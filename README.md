# istema Web de Gestión de Inventario y Ventas para Cafetería

## Descripción del Proyecto
Sistema web transaccional desarrollado para optimizar la gestión comercial y operativa de una cafetería. La aplicación permite administrar el catálogo de productos (categorías y stock), controlar las ventas en caja en tiempo real, gestionar clientes, y asegurar el acceso mediante perfiles de usuario y bitácoras de inicio de sesión.

El proyecto está diseñado bajo un enfoque académico para la materia de **Base de Datos II**, implementando características avanzadas en el motor relacional como disparadores (*triggers*), vistas (*views*), u otros posiblemente se vaya aprendiendo en la materia

---

## Tecnologías y Herramientas Utilizadas

### Frontend & Entorno de Desarrollo
* **HTML5 & JavaScript (ES6):** Estructura y dinamismo de la interfaz de usuario.
* **Tailwind CSS:** Framework de estilos utilitarios para un diseño moderno, limpio y totalmente personalizado.
* **Vite (Node.js):** Entorno de empaquetado y servidor de desarrollo rápido (ejecutado mediante `npm run dev`).

### Backend & Servidor
* **PHP:** Lenguaje del lado del servidor para procesar la lógica de negocio, control de sesiones y peticiones.
* **XAMPP Server (Apache):** Servidor local para la ejecución del entorno backend.

### Base de Datos
* **MySQL:** Sistema de gestión de base de datos relacional.
* **MySQL Workbench:** Herramienta para el diseño del modelo Entidad-Relación y administración de scripts SQL.

### Control de Versiones
* **Git & GitHub:** Control de versiones del código fuente y repositorio del proyecto.
